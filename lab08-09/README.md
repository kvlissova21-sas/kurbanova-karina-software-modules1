Контрольные вопросы
1.	С чего начинается разработка блок-схемы по условию?
Ответ: С анализа условия задачи. Сначала нужно понять, что требуется получить, затем выписать входные и выходные величины, их смысл, единицы и ограничения, записать формулы, определить промежуточные величины и их начальные значения, выбрать структуру и только потом рисовать схему.
2.	Зачем указывать ограничения и единицы измерения?
Ответ: Ограничения показывают, какие данные допустимы.
Единицы измерения нужны, чтобы понимать физический смысл величин
3.	Когда достаточно линейного алгоритма?
Ответ:  Когда все действия выполняются последовательно, без выбора и повторений
4.	Как выбрать условие для определения большего числа?
Ответ: Используется одно условие сравнения a > b. Если оно истинно, то большим является a, иначе — b. 
5.	Почему важно проверять значения ровно на границе диапазона?
Ответ: Чтобы убедиться в корректности выбора условий и отсутствии «дырок» или пересечений в логике.
6.	Как объединяются ветви перед общими действиями?
Ответ: С помощью слияния линий потока (стрелок) в одну точку перед блоком вывода или следующим общим действием.
7.	Какие начальные значения нужны счётчику и накопителю?
Ответ: Накопителю — начальное значение 0, чтобы было с чем выполнять первое сложение.
Счётчику — начальное значение 1, потому что в наших задачах суммирование начинается с 1
8.	Как проверить правильность количества повторений?
Ответ: Выполнить трассировку и посчитать число проходов тела цикла; сравнить с ожидаемым: для суммы от 1 до N тело выполняется N раз; проверить граничные случаи: N = 0, N = 1, N = 4.
9.	Чем ожидаемый результат отличается от результата трассировки?
Ответ: Ожидаемый результат вычисляется независимо от схемы
Результат трассировки получается пошаговым выполнением схемы.
10.	Какие материалы этой работы можно использовать при последующем написании программы?
Ответ: Таблицы входных, выходных и промежуточных величин с их ограничениями и единицами; сами блок-схемы как визуальный план логики; подобранные тестовые данные с ожидаемыми результатами.
